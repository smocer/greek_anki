# Vocabulary labels and addition weeks

Topic belongs to the original card. Word categories are generated by tokenizing Greek sentences and tagging each word in context. For example, `Κάνω την άσκηση.` supplies a verb, an article and a noun. Category previews show deduplicated word forms, a source sentence and its translation. Category practice uses original source cards and preserves their review history; sentence translations are not presented as standalone word definitions.

Add cards to the existing Dart source decks. Install the local annotation tools once:

```powershell
python -m venv .dart_tool/vocabulary_nlp
.dart_tool\vocabulary_nlp\Scripts\python.exe -m pip install -r tool/vocabulary_nlp_requirements.txt
```

After adding or editing vocabulary, run:

```powershell
.dart_tool\vocabulary_nlp\Scripts\python.exe tool/sync_vocabulary_metadata.py --dart C:\src\flutter\bin\dart.bat
```

New cards receive a fixed Monday timestamp and their words receive automatic part-of-speech tags. Manual card labels are optional. The addition date defaults to Europe/Bucharest; use `--timezone` to change it or `--added-on YYYY-MM-DD` for a known import date. Existing card and word dates are preserved. Reusing a word in a new sentence does not reset its first addition week. Flutter uses generated Dart data, requiring no Python or model download at runtime.

Automatic analysis uses the Greek spaCy model, authored verb forms, reviewed vocabulary and contextual corrections. Ambiguous short phrases may need review. Edit `tool/vocabulary_token_overrides.json`: `words` applies to a lowercase word throughout the library; `cards` applies to a zero-based token index within an original deck/card identity. Corrections contain `labels` and optionally `lemma`. Rerun sync after corrections. Particles outside the ten requested categories remain available under Topic.

`tool/vocabulary_metadata.json` preserves card dates and reviewed head labels. `tool/vocabulary_tokens.json` caches annotations; `tool/vocabulary_word_dates.json` preserves first addition weeks for each word/category. Sync rebuilds `lib/data/vocabulary_metadata.dart` and `lib/data/vocabulary_words.dart`.

The current migration uses each source file's first Git commit date, rather than inventing exact pre-import dates. All 497 distinct card identities in the 500-card topic collection fall in the week of 2026-09-28. Future additions in another week will automatically form another colour group after syncing. Missing dates stay black and display “Addition date unknown”. Colour ranks come from the whole library, so filtering does not change a week's colour.
